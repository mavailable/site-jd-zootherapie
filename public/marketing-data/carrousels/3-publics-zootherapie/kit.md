## 🚀 Comment publier

1. Sur **LinkedIn desktop**, clique sur **"Commencer un post"**
2. Dans les icônes média, clique **"+ Ajouter un document"**
3. Upload le PDF du thème choisi (ex : `3-publics-zootherapie-soin.pdf`)
4. Quand LinkedIn demande le **titre du document**, colle :
   `Pour qui marche vraiment la zoothérapie ?`
5. Dans le champ texte, colle le **copy** ci-dessus
6. Publie
